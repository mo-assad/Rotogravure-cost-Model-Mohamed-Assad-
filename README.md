# Rotogravure Cost Model

A professional pricing and cost estimation tool designed for the flexible packaging and rotogravure printing industry. This tool helps packaging professionals, estimators, and business strategists quickly evaluate technical packaging specifications, calculate accurate production costs, and optimize pricing strategies.

## Features
* Swift technical evaluation of packaging specifications (density, micron thickness, and grammage).
* Accurate costing framework tailored for rotogravure printing.
* Streamlined calculations to support business development and industrial B2B decision-making.
